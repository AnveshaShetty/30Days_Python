## 📚 Concepts Learned

### Variables

Created variables to store different types of data.

```python
first_name = 'Anvesha'
age = 20
is_married = False
```

---

### Data Types

Used the `type()` function to identify the data type of different variables.

Examples:

- `str`
- `int`
- `bool`

---

### String Functions

Used the `len()` function to find the length of a string.

```python
print(len(first_name))
```

Compared the length of two strings.

```python
print(len(first_name) == len(last_name))
```

---

### Arithmetic Operators

Practiced the following operators:

| Operator | Purpose |

| `+` | Addition |
| `-` | Subtraction |

| `/` | Division |
| `%` | Modulus (Remainder) |
